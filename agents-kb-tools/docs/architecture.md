# ארכיטקטורת agents-kb-tools

עודכן: 2026-11-09.

מקורות המוצר תחת src: פקודות ב־tools, קוד משותף ב־shared, חוזים ב־method
ומקורות סקילים ב־skills. docs מתעד את מימוש הרכיב ופיתוחו. החוזה המחייב הוא
[חוזה הכללים](../src/method/rule-contract.md).

הכלים ב־TypeScript ונבנים מראש ל־JavaScript. עטיפות bin שומרות את שמות
הפקודות ומוסרות את הקשר נקודת הכניסה של מסלול התאימות הוותיק.
מרשם בנייה מכיל חתימות ומצאי מקורות; CLI מסרב לתוצר חסר או מיושן.
הפצת npm כוללת runtime מאוגד ומקורות לאימות, ללא צורך בקומפיילר בזמן ההרצה.
ask הוא רכיב נפרד שנשאר Python בשל חיבורו ל־Recoll.

לכל מופע פרופיל מקומי. המנוע מאמת מקור יחיד לכל כלל ומפיק תמציות נפרדות
לסשן ולמבקר, תוצרים טבעיים ללקוחות ומרשם בחירה. הגופים נשארים במופע.
פרופיל אינו הרשאה. נשמרו aliases, תקציבים, הפרש פרויקט והפניות קנוניות.

התקנה מופרדת מיצירת תמציות. ממשק JSON מקבל פעולות או תוכנית מפורשת;
גיבוי גרסה 1 ו־optimistic guards מאפשרים שחזור בלי לדרוס עריכה מאוחרת.
בחירת לקוחות, יעדים ותוכן מקומי שייכת למתאם המופע. build אינו מחבר התקנה.

לשיטה מקור יחיד ב־src/method. מחולל הסקילים מעביר את תיקיית הסקיל בשלמותה,
שומר בתים והרשאות של קובצי עזר, ומצרף מקורות שיטה דרושים תחת
references תוך התאמת הפניות. ההפצה המובנית dist/skills משתמשת בהרשאות
0644/0755 שתואמות לאריזת npm; ייצוא נפרד שומר הרשאות מקור מדויקות. מרשם בעלות מאפשר ניקוי משאב מיושן שנוצר,
תוך סירוב למחיקת קבצים זרים או לדריסת עריכה מקומית. לפרטי ההפעלה קרא
את [נוהל ההתקנה](../src/method/installation.md).

המודל הקודם ומימושי Python/Bash/awk זמינים ב־Git; נקודות הבסיס ופקודות
השחזור מתועדות ב־[יומן](walkthrough.md). נשמרו בדיקות ההתנהגות, בלי עותק
מנוע ישן בעץ הפעיל. מעבר התקנות חיות הוא שלב נפרד משינוי מקורות המוצר.
