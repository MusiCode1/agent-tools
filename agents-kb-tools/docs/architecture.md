# ארכיטקטורת agents-kb-tools

עודכן: 2026-11-07.

המוצר נשמר ב־src: מנוע Python ב־kb_tools, חוזים ושיטת עבודה ב־method,
וסקילי שימוש והתקנה ב־skills. מסמכי docs מתארים את פיתוח הרכיב ואת ההחלטות.
מקור מפרט התמציות הוא [חוזה הכללים](../src/method/rule-contract.md).

לכל מופע פרופיל מקומי: מקורות, תחולה, aliases ותקציבי פלט. המנוע קורא מקור
אחד לכל כלל, מאמת אותו, בוחר לפי יעד והקשר ומפיק קבצים לסקירה. הגופים המלאים
נשארים במופע; הפניות המקור נוצרות מהנתיב בפועל. פרופיל אינו הרשאה לבצע פעולה.

הפרדת היעדים מאפשרת הנחיית עבודה לסוכן ובדיקת גבולות הרשאה למבקר, בלי להזריק
למבקר את כללי השפה והדיווח. אין fallback שקט לגוף המלא, ואין חיתוך בתקציב.
מחולל מספק גם קובצי טעינה טבעית משום שפלט סשן עשוי לחרוג מתקציב hook.

bin/kb-rules הוא נקודת הכניסה החדשה. kb-build-agents מפנה אליו רק עם --profile.
כלי knowledge.conf האחרים נשארים כלי תאימות. אין התקנה, שינוי קונפיג או הפעלת
מערכת חיה בתוך המחולל. חיבור הצרכנים הוא שלב מפורש עם סקירה ואימות חדשים.

המודל הישן, שבו כללים חיו ליד הישויות והתחולה נגזרה מהנתיב, נשמר בהיסטוריית Git.
נקודת הבסיס ופקודות השחזור מתועדות ב־[יומן](walkthrough.md). תוכניות phase1–phase4
של המודל הקודם נגישות מהבסיס המתועד ב־Git; הן הוסרו מהעץ הפעיל כדי שלא
יתחרו במקור החוזה החדש או ישכפלו פרטי מופעים.
