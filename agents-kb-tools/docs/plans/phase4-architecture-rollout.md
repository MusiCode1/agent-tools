### סשנים — הצורה הגולמית של `history/`

**אינם שכבה חמישית.** המנגנון כבר קיים ומנתב נכון:

```json
"repos":  { technical: agent-sessions · work: team-docs-repo/… ·
            personal: agent-sessions-personal }
"routes": [ team*/app* → work · project-e*/person* → personal ]
```

שלושה יעדים, **אף אחד בלי remote** — זה בדיוק "מי מורשה לראות", שהוקם
קודם ולצרכים אחרים.

| | `history/` | סשנים |
|---|---|---|
| מה | המסקנה | השיחה |
| נכתב | ביד, בזמן הלמידה | אוטומטית |
| נפח | עשרות | **25,917** |
| נקרא | כדי לא לחזור על טעות | פורנזיקה |
| אינדקס | `~/.recoll` | `~/.recoll-sessions` |

```
סשן ──(זיקוק ידני)──→ history/ ──→ wiki · runbook · rules
```

**מה שחסר הוא חיווט, לא בית חדש:**

- **C4** — הבידוד קיים **ברמת הריפו ולא ברמת החיפוש**. 60MB של סשנים
  אישיים יושבים היום ב-`~/.recoll-sessions` יחד עם הטכניים.
- **C5** — זיקוק בלי הפניה לגולמי מאבד את הפורנזיקה.
- **C6** — 950MB שגדלים תמיד. `history/` נצבר בעשרות ונשמר לנצח;
  סשנים בעשרות אלפים וצריכים מדיניות נפרדת.

**5 מ-15 הרשומות ב-`failures.md` כבר הוכיחו את עצמן** — נלמדו מחדש
מאפס אחרי ההקפאה (`port 4000`, `merge to dev`, `playwright as root`,
`NDJSON newline`, `OneCLI`).

- **testing:** רשומה נמצאת לפי תגית ולפי `[[ישות]]` · `~/.recoll` מחזיר
  0 על תיקיית הסשנים הפרטיים · שיחה שנמחקה מהדיסק עדיין נמצאת.
