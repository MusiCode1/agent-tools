# עבודה על agents-kb-tools

המוצר הוא קוד, חוזים וסקילים תחת src. תיעוד הפיתוח והחלטותיו תחת docs.
כל כלי בתיקייה משלו תחת src/tools; קוד שמשמש כמה כלים ב־src/shared.
לפני שינוי חוזה קרא src/method/rule-contract.md; לפני שינוי חלוקת תוכן קרא
src/method/knowledge-method.md; לפני שינוי אריזה או התקנה קרא src/method/installation.md.

כלי המוצר ב־TypeScript ונבנים ל־JavaScript עבור Node.js 22 ומעלה. ask הוא רכיב
נפרד שנשאר Python. צרכנים מפעילים bin במפורש, ללא python3 או import של kb_tools.
ממשק ההתקנה מקבל JSON; אין התקנה בזמן import או build.

שמור תאימות לפקודות הוותיקות, למשתני המופע ולמסלול ללא --profile.
הכלים אינם בוחרים התקנות אוטומטית. אין להכניס פרופילי משתמש, כתובות חיות,
מרשמים פרטיים, מזהים או דוגמאות מחומר אישי.

הכנה: npm ci. אימות: npm run check, npm run build, npm test. בנה אחרי שינוי
מקור ובדוק גם הפצה מחוץ לריפו. dist ו־node_modules אינם מקורות ואינם נשמרים ב־Git.
לפני קומיט עדכן docs/walkthrough.md בתוצאות בפועל. לפרסום השתמש בדוגמאות
סינתטיות ובתאריך ללא שעה. מיזוג וחיבור מופע חי דורשים את ההרשאה המתאימה.
