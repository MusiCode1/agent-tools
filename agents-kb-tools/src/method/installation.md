# התקנת המוצר וחיבור מופע

הכלים, הסקילים ומופע הידע מותקנים בנפרד. שינוי התקנה חיה כפוף להרשאות
המופע; בנייה או טעינת סקיל אינן חיבור לצרכן חי.

## הכנת הכלים

Node.js 22 ומעלה נדרש. מתוך שורש רכיב הכלים מריצים `npm ci`, אחריו
`npm run check`, `npm run build` ו־`npm test`. כל checkout או worktree דורש
הכנת תוצר משלו. `npm pack` בונה חבילת הפצה הכוללת פקודות JavaScript,
תלויות מאוגדות ומקורות לאימות חתימות. תלויות הפיתוח אינן נדרשות להרצה.

נקודות הכניסה ב־bin שומרות את שמות הפקודות. תוצר חסר או מיושן נכשל עם הוראת
בנייה; אין התקנת תלויות או חזרה אוטומטית למנוע ישן בזמן ההפעלה.
לפני חיבור מופע בדוק חבילת הפצה ביעד זמני, ללא שינוי PATH גלובלי.

## סקילים

מקורות הסקילים תחת src/skills וקובצי השיטה תחת src/method. `npm run build`
מפיק חבילות עצמאיות ב־dist/skills. לייצוא ליעד נפרד:

```sh
bin/kb-package-skills --source /path/to/agents-kb-tools --output /path/to/export
bin/kb-package-skills --source /path/to/agents-kb-tools --output /path/to/export --check
```

מעבירים את תיקיית הסקיל בשלמותה, כולל references ו־manifest.json. העותקים
המופקים אינם מקורות עריכה. dist/skills נבנה בהרשאות 0644/0755 התואמות
לאריזת npm; ייצוא ליעד נפרד שומר את הרשאות קובצי המקור המדויקות. המחולל מסרב לדרוס עריכה מקומית; משאב ישן שנוצר
ולא שונה מוסר בהפקה חוזרת. כלי ההרצה מותקנים בנפרד. נתיבי המקור ממשיכים
לתמוך בקישורים קיימים מתוך checkout שלם.

## הכנת מופע

הגדר שורש, מקורות, תחולה ותקציבים בפרופיל מקומי; קרא את
[חוזה הכללים](rule-contract.md) ואת [מדריך ההפעלה](rule-injection.md).
צור מועמדים, סקור manifest ואת שני יעדי ההזרקה ובדוק `--check`.
תוכן והגדרות מופע אינם מועתקים לחבילת הכלים.

## התקנה הפיכה

`kb-installation` מקבל JSON ב־stdin ומחזיר JSON ב־stdout; שגיאות ב־stderr.
הוא אינו בוחר לקוחות או שורשי פרויקט. מתאם המופע בוחר יעדים מפורשים.

- `plan` מקבל operations ומחזיר תוכנית בגרסה 1 עם changes, before ו־after.
- `check` מקבל אותן פעולות; יוצא בקוד 1 אם נדרשים שינויים.
- `apply` מקבל plan שנבדק ונתיב backup פרטי. הוא מאמת את מצב היעדים,
  יוצר גיבוי חדש בהרשאה 0600 ומשחזר פעולות שהוחלו אם אירע כשל.
- `restore` מקבל backup; קורא גם גיבויי גרסה 1 מהמימוש הקודם ומסרב
  לדרוס יעד שנערך מאז ההתקנה.
- `toml` מקבל text ו־values ומחזיר text מעודכן תוך שמירת שאר התצורה.

פעולות: text עם path ו־text; link עם path ו־target; remove עם path;
toml עם path ו־values. תוכנית וגיבוי עשויים להכיל תצורה פרטית ואינם תיעוד פומבי.
build של תמציות אינו מפעיל פעולת התקנה.

לאחר חיבור מאושר בדוק סשן חדש, היעדר טעינה כפולה והפעלת מבקר בפועל.
שמור את הפצת הכלים הקודמת ואת הגיבוי לשחזור באותו מסלול מפורש.
