# שימוש במאגר ידע

קרא את הוראות המופע ואת חוזה הנתיבים שלו לפני כתיבה. המנגנון משותף;
הנתיבים, החשבונות, הקהלים והרשאות הפעולה הם של המופע.

- עובדה משותפת נוכחית: דף הישות ב־wiki. חפש ישות קיימת לפני יצירה.
- מדריך לאדם: library. נוהל ביצוע/אבחון לסוכן: agents/procedures או ליד הישות לפי חוזה המופע.
- כלל התנהגות: agents/rules. חומר ביצוע וראיות: agents/tasks.
- קוד ותצורה: agents/infra. מידע שהוחלף: היסטוריה לפי מדיניות המופע.

קהל אינו הרשאה או יעד הזרקה. שמור permalink ופרטי מקור; אל תרחיב תחולה אגב הזזה.
מקור אנושי גולמי אינו משוכתב או מקבל YAML בלי אישור. לפני שכתוב מהותי פעל לפי
מדיניות השימור המקומית. נוהל מתאר דרך פעולה; כתובות ומצב נוכחי נבדקים בישות ובמערכת החיה.

לפני הוספת כלל או שינוי יעד הזרקה קרא את [חוזה הכללים](../../method/rule-contract.md).
לפני חיפוש או כתיבת נוהל קרא את [שיטת ניהול הידע](../../method/knowledge-method.md).
להתקנה ולחיבור CLIs השתמש ב־kb-install. חובת תיעוד אינה הרשאה לשינוי מדיניות או נתונים.
