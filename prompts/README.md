# prompts

פרומפטים משותפים לסוכנים, גנריים לכל מכונה. כל פרומפט הוא פרויקט בתיקייה משלו:

| תיקייה | מה זה |
|---|---|
| `orchestrator/` | מתזמר ביצוע: מקבל בריף מאושר, מפעיל סוכנים מבצעים, עוקב, מאמת ומדווח לסוכן התכנון רק כשהוא נתקע |

## מוסכמות

- כל תיקייה מכילה `README.md` (מה זה, איך זה עובד, איך מפעילים) ואת הפרומפט עצמו.
- **בלי שמות ספקים, מכונות או נתיבים פרטיים.** כל מה שתלוי במופע (אילו CLI או מודלים,
  שמות כלים, נתיבי כללים ותיקיות משימות) נכנס ל**קובץ התאמות** פרטי של המופע, שנמסר
  לסוכן בהפעלה. הפרומפט מתייחס אליו בשמות תפקידים בלבד.
